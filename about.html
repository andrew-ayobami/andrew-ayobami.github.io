About this project

This project is an ongoing effort to track notable instances of military applications of artificial intelligence across a set of key countries. It is a prototype and currently uses demo / placeholder data for testing the interface and data model.

Goals

  • Build a public, researcher-friendly directory of GPAI military developments and use cases.
  • Surface trends that matter for policy, procurement oversight, and risk assessment.
  • Provide a low-friction way for researchers to contribute verified entries.

Why I uploaded early

I chose to publish a prototype early to show the project's direction and invite collaborators. If you are interested in contributing data, analysis, or technical help, please reach out — I'd love to collaborate.

Get involved

To contribute, you can:

  1. Open a pull request on the project's GitHub repository (replace entries in data.json with verified sources).
  2. Message me on Twitter: @damilxre
  3. Connect on LinkedIn: My profile

Ethics & disclaimer: This demo uses placeholder content for design/testing. Real incidences will be verified before publication. The project will avoid publishing sensitive geolocation or personal identifiable information. See README for more details.
